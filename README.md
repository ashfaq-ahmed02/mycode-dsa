# 🐍 Python Basics

A beginner-friendly collection of Python programs covering fundamental concepts. This repository is designed to help students learn Python step by step with simple examples and practice exercises.

## 📚 Topics Covered

- Variables & Data Types
- Input & Output
- Operators
- Conditional Statements (if, elif, else)
- Loops (for, while)
- Functions
- Lists
- Tuples
- Dictionaries
- Sets
- Strings
- File Handling
- Exception Handling
- Object-Oriented Programming (OOP)
- Modules & Packages

## 🛠️ Technologies Used

- Python 3.x
- VS Code / PyCharm

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/Python-Basics.git
   ```

2. Navigate to the project:
   ```bash
   cd Python-Basics
   ```

3. Run any Python file:
   ```bash
   python filename.py
   ```
